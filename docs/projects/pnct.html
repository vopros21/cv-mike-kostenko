PNCT Territories Map — Interactive Map of Portugal

Web app · 2026–present · pnct.singledev.eu · source (MIT)

Overview

Interactive map of Portugal that highlights the territories eligible under the PNCT programme (based on the official 2026-02-04 list), with links to matching Idealista property searches for each area. Selection depends on zoom: concelhos at country zoom, parishes when zoomed in, plus an "Only PNCT" focus mode. A protected-areas overlay (RNAP + Natura 2000) shows the % of each parish under protection. PT/EN language toggle (including basemap labels) and Auto/Light/Dark theme.

Tech Stack

TypeScript, MapLibre GL, Vite; Python (GeoPandas, Shapely) data pipeline; Vitest, pytest and Playwright tests; hosted on Cloudflare Pages.

Architecture

No backend: an offline data pipeline reprojects and simplifies the geodata into static files that the app loads directly. Mobile-polished (iPhone Safari safe areas, collapsible legend) with shape-aware camera limits. Covered by an e2e test suite and shipped as tagged releases (currently v0.6.0).
